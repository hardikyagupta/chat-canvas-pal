# Color Reference Guide

> ⚠️ **Superseded.** The color system was migrated to a centralized OKLCH token
> library. This file is no longer maintained.
>
> **See [COLORS.md](COLORS.md)** for the single source of truth — every token,
> its OKLCH value, role, and the source hexes it consolidated.
>
> Tokens are defined in [`src/index.css`](src/index.css) and exposed through
> [`tailwind.config.ts`](tailwind.config.ts). Never hardcode hex/rgb/hsl in a
> component — use a token.
